### Zenodo description (copy-paste)

```markdown
Verification dataset generated by SOLIDIFY, a zero-install, browser-native WebGPU phase-field instrument (https://solidify.frankcai.dev/, MIT License), for NIST Phase Field Community Hub (PFHub) Benchmark Problem 1a: 2D Periodic Spinodal Decomposition (Jokisaari et al., Computational Materials Science 126 (2017) 139–151, DOI: 10.1016/j.commatsci.2016.09.022).

Model and discretization:
- Conserved 2D Cahn-Hilliard equation: dc/dt = div(M grad(mu)), mu = f'(c) - kappa lap(c), with double-well chemical energy f(c) = rho_s (c - c_alpha)^2 (c_beta - c)^2.
- Benchmark 1a parameters: periodic square [0, 200]^2 on a 200x200 grid (dx = 1.0, dt = 0.003363), c_alpha = 0.3, c_beta = 0.7, rho_s = 5.0, kappa = 2.0, M = 5.0, c_0 = 0.5, eps = 0.01, exact Jokisaari et al. (2017) Eq. 5 cosine initial condition, integrated to t = 1000.00 (297,374 explicit steps).
- Discretization: periodic 9-point Mehrstellen isotropic Laplacian for both mu and dc/dt in centered WGSL float32 storage (u = c - c_mid), giving exact discrete zero sum and 2.25x larger explicit biharmonic CFL than a 5-point stencil.

Headline verification metrics (Intel Xe2-LPG integrated laptop GPU via headless Chrome WebGPU):
- GPU solver time: 4.09 s (15.39 s total wall time including 41 diagnostic readbacks).
- Total free energy F(t): 319.094 -> 84.370 (strictly monotone across all 41 checkpoints, max_energy_increase = 0).
- Late-stage interface equipartition at t = 1000: F_chem = 42.480, F_grad = 41.890.
- Mass conservation: <c>(0) = 0.502548 -> <c>(1000) = 0.502546 (max |delta <c>| = 1.84e-6 over 297,374 explicit f32 steps).
- Domain coarsening: L(25) = 10.72 -> L(1000) = 22.31 (log-log slope alpha = 0.196 on the finite periodic box [0, 200]^2).

Reproduce locally from the SOLIDIFY repository:
  node scripts/export-pfhub-b1.mjs --grid=200 --tmax=1000 --sample-dt=25 --port=5297 --out=pfhub/results-b1-200
```

### Solver and Discretization

- **PDE:** Conserved 2D Cahn–Hilliard equation $\partial c / \partial t = \nabla \cdot (M \nabla \mu)$ with $\mu = f'(c) - \kappa \nabla^2 c$ and $f(c) = \rho_s (c - c_\alpha)^2 (c_\beta - c)^2$.
- **Parameters:** $[0, 200]^2$ periodic, $200 \times 200$ uniform grid ($dx = 1.0$, $dt = 0.003363$), $c_\alpha = 0.3$, $c_\beta = 0.7$, $\rho_s = 5.0$, $\kappa = 2.0$, $M = 5.0$, $c_0 = 0.5$, $\varepsilon = 0.01$, Jokisaari et al. - **Hardware & Runtime:** Intel Xe2-LPG integrated laptop GPU (`8` CPU cores, `1` node, headless Chrome WebGPU), `4.09 s` GPU solver time / `15.39 s` total wall time including 41 readbacks.
